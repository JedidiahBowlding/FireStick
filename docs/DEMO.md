# 30-second demo script

**0–4s — Launch.** “This is a canvas for the biggest screen in the room—not another streaming app.” Show: *What would you like to build today?*

**4–10s — Create locally.** Select **Mind map**. Five connected cards appear instantly. Point to the footer/toast: **0 API calls**.

**10–16s — Interact.** Move the highlighted card with the D-pad, open View to zoom, then open Browser. “Every interaction so far is on the TV, instant and offline.”

**16–21s — Inspect the boundary.** Select **Organize with AI**. Pause on the confirmation sheet: one batched request, estimated tokens, nothing sent yet.

**21–27s — One high-impact call.** Confirm. Card labels and descriptions become a goal, priorities, and next steps. Point to the usage receipt: **1 AI call**.

**27–30s — Close.** “Local by default. Intelligence only when it earns the call.”

Before presenting, start the optional server and verify `/health` reports `live`. Without it, the app uses an explicitly labeled deterministic demo transform so the UI remains reviewable.
